# lab_work_2
Лабораторная работа на тему реализации уязвимостей OWASP в локальном веб-приложении.

Разработка веб-приложения FoodBook выполнялась на языке программирования Python с использованием веб-фреймворка Django. В качестве системы управления базами данных использовалась SQLite. Для создания пользовательского интерфейса применялись HTML и CSS.

В качестве среды разработки использовалась Visual Studio, а для запуска приложения, выполнения команд и проведения тестирования использовался Windows PowerShell. Для управления изменениями в исходном коде и применения исправлений использовалась система контроля версий Git.

Тестирование приложения проводилось средствами встроенного тестового фреймворка Django. Использовались Python-скрипты для демонстрации и проверки уязвимостей типа IDOR и Reflected XSS, а также для проверки корректности их устранения.
